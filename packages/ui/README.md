# UI

IDE interface: a thin web UI over the OpenCode TypeScript SDK
(`@opencode/sdk`), as proposed in
[ADR-0003](../../docs/adr/0003-existing-harness-and-mcp-tools.md). It
contains no agent logic.

Planned screens: a prompt box, the timeline of agent events, the diff of the
changes, the QA button from
[ADR-0002](../../docs/adr/0002-agent-workflow-and-qa.md), and a panel that
shows which context the context engine chose and why.

Built after the walking skeleton works; until then, static mocks of the
screens.
